## 一、学术研究（4 条）

### 1. PixelBench：像素画创建的 LLM 基准与工具型智能体环境
- **URL**：https://arxiv.org/abs/2611.20628 ｜ **抓取**：2026-11-27（发布 2026-11-16）
- **摘要**：把「文本生成像素画 + 指令编辑」形式化为基准，让 LLM 智能体写代码调用绘图工具（非扩散模型）逐笔作画，人类+多模态评审双轨打分；GPT-6 Astra 双榜第一，任务集/作品/人类排序/评审协议全公开。
- **可借鉴点**：
  1. 「智能体写代码调绘图原语（rect/line/palette）」路线在 CPU-only 环境可行（无扩散推理），与 Aseprite CLI 脚本化能力天然契合；
  2. 「多模态 LLM 当像素画评委」协议可直接抄进 CI 做出图质量门禁；
  3. 任务集可当像素画自动评测的回归基准。
- **建议**：★ 值得深挖（等代码/数据集放出后做小样复现）

### 2. EndWeaver：基于 LLM 的多结局任务冒烟测试
- **URL**：https://arxiv.org/abs/2611.32089 ｜ **抓取**：2026-11-27（录用 IEEE Transactions on Games，发布 2026-11-24）
- **摘要**：LLM「高层探索规划 + 原子任务序列」两级规划，动态构建状态转移图，多分支任务全结局覆盖，测试步数从基线百万级降到数千级（Mini RPG / Overcooked Plus / Minecraft / PySC2 四环境验证）。
- **可借鉴点**：
  1. 给 exp Demo 包加「结局/分支覆盖率」冒烟测试的方法论模板，可挂进 `exp_pipeline.yml`；
  2. 状态转移图增量构建可用于检测 Dialogue/任务树死胡同；
  3. 「步数成本」指标可直接当验收标准。
- **建议**：★ 值得深挖

### 3. 3D GameDev Arena：编码智能体从零建 3D 游戏的对战基准
- **URL**：https://arxiv.org/abs/2611.24073 ｜ **抓取**：2026-11-27（发布 2026-11-18）
- **摘要**：108 个编码智能体从零构建的 3D 浏览器游戏，自动化实机测试 + 人类盲评偏好排名，目前最大规模「AI 造游戏」横评。
- **可借鉴点**：「自动化 playtesting 评分 + 人类盲评」组合可作本队评估 AI 产出 Demo 的评审流程参考；排行榜模式适合移植到团队内部 exp 横评。
- **建议**：存档

### 4. ChatNPC：情绪感知与上下文锚定的 NPC 对话
- **URL**：https://arxiv.org/abs/2611.29372 ｜ **抓取**：2026-11-27（发布 2026-11-22）
- **摘要**：ChatNPC 框架用 LLM 工具调用实时感知玩家情绪变化，调整 NPC 对话的个性化与情感基调。
- **可借鉴点**：「情绪状态 → 对话参数」接口设计可借鉴到像素 AVG 的 NPC 情绪系统；确认 tool-calling 是 NPC 记忆/情绪落地的主流做法。
- **建议**：存档

## 二、美术 / 音频 / 内容管线工具（9 条）

### 5. PixelLab MCP Server（官方）：编码智能体内直接产像素画
- **URL**：https://www.pixellab.ai/vibe-coding （社区收录：https://mcp.so/servers/pixellab-mcp） ｜ **抓取**：2026-11-27（mcp.so 条目 2026-10-08）
- **摘要**：PixelLab 官方 MCP 服务器，Claude Code/Codex 可直接生成 4/8 方向角色、骨骼/文本动画和 tileset；另有社区封装（PixelLabRat、pixellab-forge-mcp）与「vibe coding 一个 Godot 游戏」实机教程。
- **可借鉴点**：
  1. 覆盖「角色→动画→tileset」完整 2D 链路，正对本队美术管线缺口；
  2. PixelLab 本体是纯 REST API——按「REST 优先、薄 MCP 兜底」规约可绕过 MCP 直接 curl 进 CI；
  3. 第三方 MCP 封装属「未评审」黑名单范畴，要用需先人工评审。
- **建议**：★ 可直接试装（先 REST API 小样）

### 6. Texel Studio：开源「像画家一样作画」的像素画智能体
- **URL**：https://github.com/EYamanS/texel-studio ｜ **抓取**：2026-11-27（建于 2026-04-01，最近推送 2026-10-12，259 stars）
- **摘要**：非扩散路线——智能体用像素/矩形/Bresenham 线/圆/Voronoi 填充逐笔绘制并自检迭代；Gemini/OpenAI/本地 Ollama（qwen3:8b 等）可插拔；HTTP API 提供 `sprite.generate`/`sprite.tileset`，导出 PNG 或 16 变体 autotile；许可禁竞品 SaaS、含商用自由。
- **可借鉴点**：
  1. 自托管 + 本地 8B 模型 = 无云端依赖、无按张付费，CPU-only runner 跑小样可行（慢，可过夜）；
  2. `sprite.tileset` 直接吐 autotile 变体，可接 Godot 4.7 terrain autotile；
  3. HTTP API 形态符合「参数进、产物出」薄封装纪律。
- **建议**：★ 可直接试装

### 7. Retro Diffusion（Aseprite 原生扩展）：本地运行的像素画专用模型
- **URL**：https://astropulse.itch.io/retrodiffusion ｜ **抓取**：2026-11-27（条款更新 2026-09-28）
- **摘要**：像素画专训模型以 Aseprite 扩展本地运行（GPU/CPU），带调色板/色板控制、去 AI 感，一次性买断约 $65；2026-09-28 更新生成物归属条款。
- **可借鉴点**：长在本队已在用的 Aseprite 上，摩擦最低的 AI 像素画入口；调色板锁定对齐「风格锁定」需求；条款刚更新，买前核对商用与产出物归属；GUI 插件能否进无头 CI 未验证。
- **建议**：值得深挖

### 8. Layer.ai：Reference Sets 风格训练 + Godot 插件
- **URL**：https://layer.ai/features/reference-sets （Godot 插件：https://layer.ai/integrations/godot） ｜ **抓取**：2026-11-27
- **摘要**：面向游戏工作室的「用自家美术训练自定义风格（LoRA）」云服务，Godot 插件（4.5+）可在编辑器内生成 sprite/sprite sheet/9-slice UI 并直连 TileMapLayer 铺图。
- **可借鉴点**：「拿本队已定稿像素风格训专属风格库」是风格锁定方向最对口的商业方案；插件生成 tile 直连 TileMapLayer，可打通「生成→入库→铺图」；按张计费，注意预算与数据出境。
- **建议**：值得深挖

### 9. Gamedev AI（Fredarts）v1.1.0：Godot 4.7+ 专用 MIT 开源 AI 助手插件
- **URL**：https://godotengine.org/asset-library/asset/5086 ｜ **抓取**：2026-11-27（v1.1.0，2026-10-05）
- **摘要**：MIT 协议、支持 Godot 4.7+ 的编辑器插件：65 个智能体工具（脚本/节点/TileMap/程序化地牢/动画）、程序化合成音效、可视化 shader 生成、Watch Mode 自动修控制台报错、Architect→Builder→Coder→QA 多智能体流水线，支持 Ollama/LM Studio 全本地。
- **可借鉴点**：版本与 Godot 4.7.2 精确匹配且免费开源；内置程序化音效合成可作音频小样的本地补充；本地模型路径对 CPU-only 友好（8B 级推理慢但可用）。
- **建议**：★ 可直接试装
